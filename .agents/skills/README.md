# Skills

Instructions for agents :)

| Skill                                           | Description                                           |
| ----------------------------------------------- | ----------------------------------------------------- |
| [Prepare](blueprint-prepare/SKILL.md)           | Prepare the scope and plan for a development task.    |
| [Build](blueprint-build/SKILL.md)               | Build the changes for a prepared development task.    |
| [Review & Test](blueprint-review-test/SKILL.md) | Review changes and run the configured project checks. |
| [Deploy](blueprint-deploy/SKILL.md)             | Deploy prepared changes to the requested environment. |

## Examples

```text
Use $blueprint-prepare to plan issue #123.
Use $blueprint-build to implement issue #123.
```
